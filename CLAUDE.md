# Stuck in Line: working rules

## The Brand Rule (cannot be violated)

All collateral and assets must conform to the stuckinline.com guides. No exceptions.

Before creating or changing any UI, copy, metadata, image, social asset, document or marketing material, read:

- `brand/BRAND-RULE.md`
- `brand/DESIGN-GUIDE.md`
- `brand/STYLE-GUIDE.md`
- `brand/tokens.json` (the only source of colours, name, copy and asset sizes)

Rules in short: dark only; gold (`#ffcf5c`) means "you" and nothing else; boxy characters in single-file perspective; the stage is never shown inside; name is "Stuck in Line"; voice is dry, short, curious, no hype, no exclamation marks. Raster assets are generated by `python3 scripts/build-brand-assets.py`, never hand-edited.

Run `npm run brand:check` before every commit. If something cannot conform, do not make it; ask for a guide change.

## Git

Commit every update to this repo automatically with a clear message, and push to `main`.

## Project

Browser game. Server: `server.js` (Node, ws). Client: `public/` (Three.js, portrait first). Deployed from GitHub to Railway. Tests: `npm test`.
